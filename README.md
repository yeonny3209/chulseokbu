# 출석부 (Roll Call)

폐교된 고등학교에서 출석을 부르며 돌아다니는 선생님을 피해 탈출하는 1인칭 3D 공포게임. (웹, PC 전용, 15~30분)

## 실행
```bash
npm install
npm run dev
```
브라우저에서 http://localhost:5173 을 연다. **헤드폰 + 불 끄고** 플레이 권장.

## 조작
| 키 | 동작 |
|---|---|
| WASD / 마우스 | 이동 / 시점 |
| Shift | 달리기 (소음 큼, 스태미나 소모) |
| C | 웅크리기 (무음) |
| 좌클릭 또는 F | 손전등 켜기/끄기 |
| 우클릭 또는 R (누르는 동안) | 집중광 — 선생님을 잠시 멈춤 (배터리 많이 소모) |
| E | 조사 / 줍기 / 숨기 / 나가기 |
| Q | 든 물건 던지기 (소리로 선생님 유인) |
| Space | 숨어 있을 때 숨 참기 |
| Tab | 소지품·쪽지 |
| Esc | 일시정지 |
| F1 | 디버그 표시 |

마우스 잠금이 안 되는 환경에서는 방향키로 시점을 돌릴 수 있다.

## 함께하기 (최대 6명)
시작 화면의 **함께하기**에서 방을 만들거나 방 코드로 참가한다. 서로 다른 집·다른 와이파이여도 된다.

1. 방장이 **방 만들기** → 5글자 방 코드가 나온다. 친구에게 알려 준다.
2. 친구들이 **코드로 참가**. 대기실에 이름이 모인다. (방장 포함 6명까지)
3. 방장이 **게임 시작** → 친구들은 **입장**을 누른다.

규칙
- **팀 공유 진행:** 열쇠, 퍼즐, 체크포인트를 모두 같이 쓴다. 한 명이 금고를 열면 모두 진행된다. 쪽지와 손전등 배터리는 각자 따로.
- **쓰러짐과 구조:** 선생님에게 잡히면 쓰러진다. 동료가 옆에서 **E를 3초 길게** 누르면 일어난다. 전원이 쓰러지면 마지막 체크포인트에서 다 같이 다시 시작.
- 모두 손전등을 들고 시작한다. 친구의 손전등 빛과 발소리가 보이고 들린다. 음성 채팅은 없다(디스코드 등을 따로 켜세요).
- **방장은 게임이 끝날 때까지 탭을 닫지 마세요.** 방장의 브라우저가 선생님과 이야기 전체를 계산한다.

연결 방식: 서버 없이 브라우저끼리 직접 연결(WebRTC, PeerJS 무료 중계 사용). 공유기가 직접 연결을 막으면 자동으로 중계 서버(TURN)를 거친다. 그래서 연결이 조금 느릴 수 있다.

테스트용: 주소 끝에 `?net=local` 을 붙이면 같은 브라우저의 다른 탭끼리만 접속된다(개발 테스트용).

## 배포 (무료)
```bash
npm run build      # dist/ 폴더 생성
```
- **GitHub Pages**: `dist/` 안의 파일을 `gh-pages` 브랜치(또는 Pages 설정 폴더)에 올린다. `vite.config.js` 의 `base: './'` 덕분에 하위 경로에서도 동작한다.
- **itch.io**: `dist/` 폴더를 zip 으로 묶어 "HTML 게임"으로 업로드(비공개 링크로 지인에게만 공유 가능).

## 조절하기
- 난이도·속도·소음·감지 거리: `src/config.js`
- 쪽지·대사·목표 문구: `src/story.js`
- 층/방 배치: `src/layout.js`, 가구·아이템·퍼즐 위치: `src/rooms.js`

## 에셋/라이선스
외부 이미지·소리 파일을 쓰지 않는다. 텍스처는 Canvas 로 그리고, 효과음은 Web Audio 로 합성하며, 목소리는 브라우저 TTS(임시)이다. 외부 에셋을 추가하면 `CREDITS.md` 에 출처와 라이선스를 기록할 것.
